# ACBreakz Cloud — State Blueprint (bootstraps fresh sessions; updated 2026-08-11)

Secrets: values live ONLY in `.env` (gitignored). Repo is PUBLIC — never commit keys.

## 1. COMPONENT ARCHITECTURE

**Stack:** Static site on GitHub Pages (repo `Lordner-Visual/ACBreakz`, branch `master`, push = deploy ~30-60s) · Supabase `jqowngdkgnfhaworyppo` (Postgres+Realtime+Storage bucket `media` + 3 edge functions, Deno) · fal.ai (FLUX images, stable-audio, Kling video) · Stream Deck profiles generated by Node scripts · Playwright QA (`node qa/shoot-*.mjs`).

**Topology:** 5 independent stream PCs. Each: OBS scene `ACBreakz Cloud N` with 3 browser sources `overlay/?layer=bg|hud|fx&pc=N` (1080×1920@60). Per-PC state = `stream_state` rows id 1..5. Master panel `control/` (password→30-day token). Per-PC dashboard `control/pc.html?pc=N` (no login, OP_KEY in `control/op.js`, state+events+composer only). Stream Deck = API Ninja GET → `/deck`. Writes: panel/pc/deck → edge fn (service role) → `stream_state` UPDATE + `events` INSERT → realtime → overlays. Overlay self-updates (45s no-store hash poll → reload); only `layer=fx` plays audio.

## 2. TRUTH DATA MODELS & APIs

**stream_state** (id 1..5, data jsonb):
```js
{ background:{url,name,crop}|null, banners:{rotation:[assetRow…]},
  board:{picked:{abbr:true…}, highlighted:{abbr:true…}},
  animStyle:assetRow|null,            // team-anim style; null→Classic per-team webms
  boardButtons|boardBg:assetRow|null, // null = CSS default (Gold/Navy)
  buttonAnims:[assetRow…],            // multi-select; legacy buttonAnim single may linger
  boardGrid:"buttons|checker|checkerbare|honeycomb|logos|rect84|slant",
  boardGap:-20..20 negative=overlap, boardSize:40-150, logoSize:60-200, fxIntensity:30-250,
  loopFx:{url,name,boxed,fit,image,sfxUrl,crop}|null,  // deck play_loop toggle; survives reload
  updatedAt:ms, lastWriter:"deck"|clientId|"server" }   // both stamped SERVER-SIDE by state_stamp()
```
**assets** (kind ∈ background|banner|animation|sfx|logo|style; url; meta jsonb):
`{type:upload|ai|text, text, prompt, team:abbr, group:team|oneshot, image:bool, domain:team_anim|board_button|board_bg|button_anim, base_url,button_url,bg_url,poster, effect:none|glow|fire|lightning|glitch|pop, mode:ambient|trigger, per_team, builtin, sfxUrl,sfxName ("sfxUrl" in meta = linked; null = No SoundFX beats default), crop:{x,y,z(100-600)}, fit:"full"|"box", template, hideComposer, hideRotation, deleted, deletedAt}`

**events** payload: `{pc?, team, animUrl|styleUrl+styleImage+styleFit+styleCrop+logoOverlay, sfxUrl, url, boxed, fit, image, crop}`; overlay ignores age>20s or `payload.pc !== DEVICE`.

**/deck** GET `?key=DECK_KEY&action=X[&pc=N]` (no pc = all 5; deployed `--no-verify-jwt`): `team_toggle` (server reads board → pick|restore; THE deck key action), `team_pick`, `team_restore`, `board_reset`, `highlight|unhighlight|highlight_toggle|highlight_clear` (highlight NEVER restores a team — independent of elimination), `play&name=` (ilike; boxed unless meta.fit==="full"), `play_loop&name=` (TOGGLE via loop_fx_toggle() row lock → data.loopFx; same clip stops it, a different clip switches), `banner_skip`, `set_background&name=`. `board_mode|board_visible` = retired no-ops.

**/panel** POST auth: `{action:"login",password}→{token}` | `{token}` | `{key:PANEL_KEY}` (scripts) | `{op:OP_KEY,pc:1-5}` (operator: only state/event/sign_upload `^banners\/composed-`/asset kind=banner non-template). Actions: `patch{pc,clientId,patch}` (non-board keys, atomic), `board{pc,clientId,boardAction,team}` (atomic board_action), `state{pc,data,force?}` (legacy whole-doc — board-protected unless force), `event{pc,type,payload}`, `asset{asset}`, `update_asset{id,meta}` (merge; sweeps rotation copies+bg crop; hideRotation⇒deselect), `delete_asset` (soft→trash+deselectEverywhere), `restore_asset` (clears deleted+both hide flags), `purge_asset`/`empty_trash` (remove files+rows+deselect), `sign_upload{path}`→`uploadToSignedUrl`.

**/generate-asset** POST `{key, kind, prompt, quality:"standard"|"best", mode:"inline"|"submit"|"poll", request_id, model, status_url, response_url, no_row, as:{kind,name,meta}, brand:bool, ref_url, longer:bool}`. Kinds: images(background,banner,animation_still,board_button:1024²,board_bg:1344×384) inline FLUX (`ref_url`→flux/dev/image-to-image, strength .65); `sfx`→stable-audio (queue, 1-4min); video(background_anim,board_bg_anim,button_anim)→Kling 1.6 std $0.25 / v2 master $1.40 (queue; `ref_url`→image-to-video). Loop clips duration "5"+perfect-loop prompt; `longer:true`→"10" no loop (one-shots). NO auto-branding — BRAND prefix only when `brand:true`. Poll uses `status_url/response_url` FROM SUBMIT RESPONSE.

Mgmt API SQL (schema changes): `POST https://api.supabase.com/v1/projects/jqowngdkgnfhaworyppo/database/query` with Bearer SUPABASE_ACCESS_TOKEN, `{query:"…"}`.

## 4. ACCUMULATED NUANCES & NEVER-DO RULES

- **VP9 alpha is side-channel**: ffprobe says `yuv420p` even with alpha. Decode `-c:v libvpx-vp9` (input opt), encode `-pix_fmt yuva420p -auto-alt-ref 0`, fade `fade=t=out:…:alpha=1`. M3 lost alpha this way (black bg bug). Current stingers `animations/v2/`, cropped one-shots `animations/v4/`; old flat files unreferenced.
- **API Ninja**: empty-string file fields → NullReference in `LoadHeadersAndUserData` → EVERY request dies (⚠). Must be `"No file..."`. `autorunMinutes:"0"` = fire-every-0-min crash loop; empty = off. Multi Action ✓ ≠ plugin success. Its plugin manifest is ENCRYPTED — read `PropertyInspector/*.html/js`, the DLL strings, or diff a hand-made exported button (fastest, do this FIRST next time).
- **Stream Deck**: profiles live in `ProfilesV3` (not V2). Import DUPLICATES (delete old first). PowerShell/.NET zip writes backslash entries → silent import failure. `PageIndex` 1-based. `system.open` = files only; URLs need `system.website` `{openInBrowser:true,path}`. Icons are per-key press-state only (can't track board; accepted cosmetic drift). Icon art: `streamdeck/icons/*`.
- **Write model (V11 — replaces the old "echo clock" rule)**: `data.board` is written ONLY by `board_action()`; every other top-level key ONLY by `state_patch()`/`state_replace()` (`supabase/migrate-v11-atomic.sql`, applied). All three `select … for update` the row and lock PCs in ASCENDING id order (deadlock-free). That row lock IS the queue — an app-level queue was rejected: a dead worker returns 200 for a press that never applied. NEVER do I/O while holding the lock — the edge fns pre-resolve stinger/sfx assets and pass them as `p_fx`. The FX event inserts in the SAME transaction and only on a real transition, so a stinger cannot play for an elimination that did not record (pre-fix, measured: 12 stingers fired, 1 recorded; 12 simultaneous presses landed 1). `updatedAt`/`lastWriter` are stamped in ONE place (`state_stamp`, Postgres `clock_timestamp()`); pages suppress their own echo by `lastWriter === CLIENT_ID` and drop out-of-order realtime by `updatedAt < current` — that comparison is valid ONLY because of the single clock; the old browser-vs-edge one silently dropped real writes and then re-pushed over them. Each page keeps ONE write in flight and coalesces pending patches (concurrent same-key patches otherwise land out of order). Anon must stay denied on all three RPCs (grants are service_role only). `qa/shoot-concurrency.mjs` + `qa/shoot-panel-race.mjs` guard it; the old "panel writes first, 1.2-1.5s apart" QA rule is retired.
- **Restart ≠ rebuild**: to restart a playing `<video>`, SEEK it (`currentTime=0;play()`). Removing/recreating the element drops to readyState 0 → blank frame until re-buffer + one refetch per cell per change (v10 bug: "any change kills the button animations" — only bit the AI-clip path, CSS builtins restart free, so v9's acceptance missed it). New elements need `autoplay:true` — no blanket play() loop exists anymore. QA that frame-samples races the CDN cache and can pass on broken code; assert on element identity (dataset tags surviving) + refetch counts instead.
- **Master/PC list parity**: any list rendered in BOTH `control/index.html` and `control/pc.html` must use the IDENTICAL filter — the dashboards have no delete, so anything they list that master doesn't is unremovable (pc.html listed `kind:"background"` as composer art long after master narrowed to banner-only ⇒ 9 undeletable cards). Composer membership = `inComposer()` in master: `url && kind==="banner" && meta.type!=="text"`, minus `hideComposer`. These lists derive from the shared `assets` row, NOT per-PC state — there is nothing to migrate, fixing the predicate syncs all five instantly. `qa/shoot-composer-sync.mjs` guards it.
- **Deletion**: every removal path (delete/purge/empty_trash/hideRotation) MUST `deselectEverywhere` or OBS shows blank frames. Rotator also skips missing files via `onerror`. Purge is REFERENCE-COUNTED (`unreferencedFiles` in panel fn): "file into section" makes a second row pointing at the SAME storage file, so a file is only removed when no surviving row's url/base_url/button_url/bg_url/poster/sfxUrl points at it — before this, purging the original deleted the file under the filed copy (lost 2 AI clips 2026-08-11). `qa/shoot-purge-refs.mjs` proves it; judge storage existence by BUCKET LISTING, the public URL serves CDN-cached 200s long after deletion (also why a dead file can keep "working" in an open overlay).
- **Audio**: keep `Audio` refs in a Set until ended (GC aborts request); only `layer=fx`/`all` plays sound — "sound but no stinger" ⇒ fx source missing in OBS.
- **fal.ai**: FAL key starts lowercase `c` (phone auto-capitalize bit us). Queue poll URLs MUST come from submit response (nested model ids break constructed URLs). Effect gens need "isolated on pure black, no text" + negative_prompt; a global brand prefix hijacks them (now opt-in `brand:true`). stable-audio/Kling take 1-5min — always queue via submit/poll, never inline.
- **Reframe crop**: `crop{x,y,z}` needs a CLIPPING ancestor or a zoom spills instead of cropping — FX one-shots/stingers render inside `.fxbox` (owns geometry + overflow:hidden), the media just fills it. A running `@keyframes` outranks an inline `transform`, so the still-image pop takes the zoom as `--rfz` and MULTIPLIES it in rather than being overwritten. Clamp is 600% in overlay AND panel (they disagreed: panel 600, overlay 400). Board backgrounds and button textures crop too: a still board bg is a real `<img>` in a clipping wrapper (`makeStill`), and a button texture uses `--btnzoom`/`--btnpan` (background-size/position) since there is no per-cell element. **`applyBoardParts` change key MUST include both crops** — it early-returns on an unchanged key, so a crop-only edit silently did nothing no matter what the render path could do. `qa/shoot-fx-crop.mjs`.
- **Board scale**: `boardGap` -20..20 — CSS `gap` cannot be negative, so overlap shrinks the grid TRACK below `--tile` and lets each cell overflow its own track by |gap|; positive spacing still uses a real `gap`. `boardSize` 40-150 (>100 hands back the board padding so nothing crops to ~127%; past that the outer teams go off-canvas, accepted). `logoSize` 60-200 (>100 drives `--logofrac` NEGATIVE so the logo spills; needs `#board.logo-spill` to drop `.cell{overflow:hidden}`). Any per-grid `--logopad` override MUST be expressed as an offset from `var(--logofrac)` or the Logo slider silently dies on that grid. `fxIntensity` scales brightness/size ONLY — never divide an animation duration by it.
- **CSS**: `inset:auto` shorthand must precede `left/top` in the same block. Pseudo-element existence: check `content!=="none"` (display lies). `#board::after` absolute is safe in grid. Honeycomb rows offset ±.25 tile to stay in safe area.
- **Board rules**: eliminate-only (no fill mode, no X, dim = `brightness(.38) saturate(.55)`); highlight is INDEPENDENT of elimination — eliminating keeps `highlighted[team]` (overlay hides the anim via `.hl = hl && !picked`, star returns on restore; deck highlight icons stay truthful), and highlight actions never restore a team (only team_toggle/team_restore/eliminate-tap do); panels show star + OUT together (star is `.hl::before`, OUT is `.on::after` — same pseudo would collide); effects only on `.hl`; 100% size = max that fits — never let tiles cross x111/x968.
- **Panel/QA**: page reload re-locks the login — switch PCs via `#pcSel` in tests. Assets render newest-first (`cards[0]` = newest). Playwright needs `--autoplay-policy=no-user-gesture-required`.
- **PowerShell**: 5.1 — no `&&`, no ternary; `Set-Content` on files with non-ASCII → mojibake (use Write/Edit tools or Node). RNG: `RNGCryptoServiceProvider` (`::Fill` missing, returns zeros silently!).
- **Spend**: never >10 AI images unbatched; log to BUDGET.md. Repo PUBLIC: secrets only in `.env`/`*.local*`; OP_KEY intentionally public (state-only blast radius) until repo goes private.
- After every deploy, poll Pages for a marker string before running QA (`grep` hosted file, 3×10s typical).
